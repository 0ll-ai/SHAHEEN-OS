## 👋🏻 开始使用 & 交流

欢迎使用 SHAHEEN OS — 一个面向团队和企业的 AI Agent 平台。请在使用过程中将任何问题或建议提交到仓库 Issues： [https://github.com/0ll-ai/SHAHEEN-OS/issues](https://github.com/0ll-ai/SHAHEEN-OS/issues)

> **重要提示**：本项目正在持续开发中。请在生产环境中按照文档部署，并保护你的密钥与凭据。

## ✨ 特性一览

- Agent 管理与调度
- 持久化可编辑记忆
- 多模型与多供应商支持
- 插件系统与工具链集成
- SPA、桌面 (Electron) 与 CLI 多端支持

## 🛳 自托管

本仓库包含 Docker Compose 示例与环境变量示例，用于在私有基础设施中部署 SHAHEEN OS。请参阅 `docker-compose/` 中的示例文件与本仓库根目录的 `.env.example`。

## ⌨️ 本地开发

```bash
# 安装依赖
pnpm install

# 启动开发 (Next.js + Vite)
pnpm run dev
```
